Step 2: User Authenticates on WordPress

The user will be redirected to WordPress where they can log in and approve the application. After approval, WordPress will redirect back to your callback URL with credentials.

💡 WordPress Requirements

No custom plugin is required! WordPress has built-in support for Application Passwords in core (WP 5.6+). However, ensure your WordPress site meets these criteria:

  • Uses HTTPS (SSL enabled), as WordPress disables Application Passwords on insecure HTTP unless explicitly enabled for dev.
  • Application Passwords feature is enabled on the user account (WP Admin → Users → Profile).
  • Site URL points to a real WordPress installation where /wp-admin/authorize-application.php exists.

What happens in WordPress:

  1. User logs into WordPress (if not already logged in)
  2. User sees the application authorization page
  3. User approves the application
  4. WordPress generates an application password
  5. WordPress redirects to your callback URL with credentials

For Demo Purposes:

Since this is a demo, you can simulate the callback URL. In a real application, WordPress would redirect to your callback URL automatically.

Example: https://myapp.com/callback?user_login=john&password=abc123&success_url=https://myapp.com/success

Integration Code Examples

Python

import requests

# Generate auth URL
response = requests.post('http://localhost:8000/api/v1/auth/url', json={
    'wp_root_url': 'https://example.com',
    'app_name': 'My App',
    'callback_url': 'https://myapp.com/callback'
})
auth_url = response.json()['auth_url']

# Parse callback
response = requests.post('http://localhost:8000/api/v1/auth/callback', json={
    'callback_url': callback_url
})
credentials = response.json()

# Validate credentials
response = requests.post('http://localhost:8000/api/v1/auth/validate', 
    headers={'X-API-Key': 'your-api-key'},
    json={
        'user_login': credentials['user_login'],
        'password': credentials['password'],
        'wp_root_url': 'https://example.com'
    }
)
user_profile = response.json()
